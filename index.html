01

Application de gestion de groupes TD/TP

Déc. 2025 · projet BUT · trinôme

  • Java
  • SQL
  • HTML/CSS
  • GitLab
  1. SSituation

    Projet de BUT en trinôme : concevoir une application de gestion d'une promotion d'élèves et de leurs groupes de TD/TP.

  2. TTâche

    Développer l'application complète — modèle de données, back-end Java, interface web — dans les délais impartis.

  3. AAction

    Java & SQL pour la logique métier, HTML/CSS pour l'interface. Collaboration et versioning via GitLab.

  4. RRésultat

    Application fonctionnelle livrée en trinôme. Maîtrise du travail collaboratif et de l'intégration multi-langages.

Jeu vidéo en C++

Oct. 2024 · projet BUT

  • C++
  • Game dev
  1. SSituation

    Projet BUT : développer un jeu vidéo en C++ avec contraintes de déplacement dans une zone définie.

  2. TTâche
