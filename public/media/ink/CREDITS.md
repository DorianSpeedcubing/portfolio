# Ink backdrop assets — sources & licenses

All images are recolored to white-on-transparent via `npm run ink:process`
(`scripts/ink-to-white.mjs`).

> ⚠️ The current files are PLACEHOLDERS from stock sites (Adobe Stock previews,
> pngtree, png-clipart) and are NOT licensed for public deployment. Before launch,
> replace each `ink-src/` source with a CC0 / public-domain equivalent
> (museum open-access: The Met, Cleveland, Smithsonian; rawpixel public domain;
> Wikimedia Commons; openclipart) and re-run `npm run ink:process`.
